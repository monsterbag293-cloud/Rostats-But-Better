# Rostats-But-Better

A lightweight Roblox live stats counter inspired by RoStats.

## Features
- Search any Roblox username.
- Displays avatar, display name, and account metadata.
- Live counters for followers, following, friends, public game count, and total visits.
- Refreshes automatically every 15 seconds.

## Run locally
```bash
python3 -m http.server 4173
```
Then open `http://localhost:4173`.

> Note: This app uses `roproxy.com` API mirrors so browser requests can work without a backend proxy.
